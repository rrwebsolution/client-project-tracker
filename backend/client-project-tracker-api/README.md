# Client Project Tracker — API

This is the Laravel REST API backend for the Client Project Tracker application.

See the project root README (in the `client-project-tracker-web` frontend project)
for full setup instructions, API documentation, and technical decisions:

- Install: `composer install`, configure `.env` for MySQL, `php artisan migrate --seed`, `php artisan serve`
- Tests: `php artisan test`
- Endpoints: `GET|POST /api/projects`, `GET|PUT|DELETE /api/projects/{id}`
